# Lunar He-3 Ground Truth Generation (Phase 1)

Code and simulation environment for generating sub-pixel He-3 concentration
ground truth fields over two lunar test regions, supplementary to the
accompanying paper.

Kaguya MI gives FeO and OMAT at ~59 m/pixel. We crop a ~500x500 m window per
region directly from the remote USGS mosaic, convert FeO to TiO2 (Lucey 1998),
upsample everything to a 500x500 grid with bicubic interpolation, then add
sub-pixel variability with a correlated Gaussian random field on FeO and OMAT
only. TiO2 is re-derived from the perturbed FeO through the same Lucey
relation rather than perturbed on its own, so the FeO-TiO2 relationship never
breaks. He-3 is computed last from the resulting TiO2/OMAT with the Fa & Jin
(2007) model. Full step-by-step description: [docs/METHOD.md](docs/METHOD.md),
regenerated by the script on every run.

## Regions

| Region | Center | Setting | Solar wind flux factor F |
|---|---|---|---|
| A | 0.674N, 23.473E | Mare Tranquillitatis (Apollo 11), high-Ti mare basalt | 0.50 |
| B | 8.973S, 15.500E | Descartes Highlands (Apollo 16), anorthositic highlands | 0.48 |

## Data source

Kaguya MI mineral maps, USGS Astrogeology Science Center (Lemelin et al.,
2015/2016), hosted at:
`https://planetarymaps.usgs.gov/mosaic/Lunar_MI_mineral_maps/`

References:
- Lemelin, M., Lucey, P.G., Song, E., Taylor, G.J. (2015). Lunar central
  peak mineralogy and iron content using the Kaguya Multiband Imager:
  Reassessment of the compositional structure of the lunar crust.
  *J. Geophys. Res. Planets*, 120, 869-887.
- Lucey, P.G., Blewett, D.T., Hawke, B.R. (1998). Mapping the FeO and
  TiO2 content of the lunar surface with multispectral imagery.
  *J. Geophys. Res.*, 103(E2), 3679-3699.
- Fa, W., Jin, Y.-Q. (2007). Quantitative estimation of helium-3 in
  lunar regolith. *Icarus*, 190(1), 15-23.

## Repository layout

```
scripts/    generate_he3_groundtruth.py  - full pipeline, single entry point
data_raw/   remote-cropped FeO / OMAT GeoTIFFs (9x9 px, as downloaded)
data_processed/   intermediate TiO2, interpolated and GRF-perturbed arrays
outputs/    final He-3 ground truth fields (.npy and GeoTIFF)
figures/    heatmap visualizations for each region and variable
docs/       METHOD.md, auto-regenerated by the script on every run
```

All file paths are relative to the script location, so the repository can
be cloned and run from any location without modification.

## Setup

GDAL's Python bindings are easiest to install through conda:

```
conda env create -f environment.yml
conda activate he3
```

Alternatively, on a system with the GDAL C library already installed,
`pip install -r requirements.txt` can be used instead.

## Running

```
python scripts/generate_he3_groundtruth.py
```

The script fetches the required ~9x9 pixel crops over HTTP range requests
(no full mosaic download), so it needs network access but only transfers a
few kilobytes per region. Re-running reproduces the same statistics: the
random fields are seeded (seed=42), and each region's field is drawn from
an independent slice of the same advancing random generator.

## Outputs

For each region, the script writes:
- `outputs/region{A,B}_he3_groundtruth.npy` / `.tif` - final He-3 field,
  500x500 grid, ppb units
- `figures/region{A,B}_{feo,tio2,omat,he3}.png` - heatmap visualizations,
  He-3 on a fixed 0-15 ppb scale for cross-region comparison
- `figures/region{A,B}_he3_adaptive.png` - same He-3 field, colorbar scaled
  to that region's own min/max (useful when the range is narrow, e.g. highlands)
- `docs/METHOD.md` - method description matching the exact steps executed
